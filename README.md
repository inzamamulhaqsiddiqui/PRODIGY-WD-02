# PRODIGY-WD-02
⏱️ Digital Stopwatch with Laps
📌 Project Overview
This project is a digital stopwatch application that allows users to start, stop, reset, and record lap times. It features a modern user interface with gradient backgrounds and interactive buttons, providing an intuitive and visually appealing user experience.

🎯 Objective
As part of my Web Development Internship at Prodigy InfoTech, the goal of this task was to:

Implement a functional stopwatch using HTML, CSS, and JavaScript.

Enhance the UI/UX with modern design principles.

Demonstrate proficiency in DOM manipulation and event handling.

🛠️ Technologies Used
HTML5: Structuring the web page content.

CSS3: Styling the application with gradients, flexbox, and responsive design.

JavaScript (ES6): Implementing stopwatch functionality and DOM interactions.

🚀 Features
Start/Stop Functionality: Control the stopwatch timing.

Reset Functionality: Reset the stopwatch to zero.

Lap Recording: Record and display lap times.

Responsive Design: Ensures usability across various devices and screen sizes.

Modern UI: Gradient backgrounds and interactive buttons enhance user engagement.

You can open the file directly or use a live server extension if you're using VS Code.
